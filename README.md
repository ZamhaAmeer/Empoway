# EMPOWAY – Empowering Every Journey

**Empoway** is an inclusive web-based platform designed to help people with disabilities, elderly individuals, and wheelchair users discover accessible public places across Sri Lanka. It provides accessibility information, photographs, and community contributions to help users make informed decisions and explore with confidence.

## 🎯 Project Objectives

- Promote accessibility and inclusion.
- Help users discover wheelchair-friendly public places.
- Provide reliable information about accessibility facilities.
- Encourage community participation through reviews, reports, and photo contributions.
- Support independent mobility and confident journeys.

## ✨ Key Features

- **Explore Accessible Places** – Discover hospitals, universities, banks, government offices, restaurants, and more.
- **Accessibility Information** – Check ramps, step-free entrances, elevators, accessible toilets, and parking facilities.
- **Interactive Map** – Find places using map-based navigation.
- **Place Details** – View locations, photographs, and accessibility information.
- **Community Contributions** – Submit new places, upload photographs, and share accessibility updates.
- **User Authentication** – Secure registration and login.
- **User Dashboard** – Manage personal profiles and contributions.
- **Admin Dashboard** – Manage users, places, submissions, and accessibility reports.
